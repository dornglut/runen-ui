# M10 Conformance Matrix

> **Category:** Target architecture
>
> **Status:** M10B owner-accepted; M10C, M10D, M10E, and M10F blocked
>
> **Milestone:** M10
>
> **Reviewed baseline:** `0dfef8bab6f99be6dd6e822e6febaafe57b03485`
>
> The four M10B text-coordinate/caret-map observations are accepted current
> behavior. The remaining rows freeze target observations only; they do not claim
> that transactional editing, framework services, production scrolling,
> controller normalization, or the supported touch profile exist.

[ADR 0018](../adr/0018-editable-text-and-interaction-services.md) owns M10
architecture. M4 remains authoritative for routed input, composition lifetime,
capture, FIFO application actions, effects, scheduling, and terminal poison. M5
remains authoritative for semantic identity, publication, actions, and testing.
M8 remains authoritative for shaping, line breaking, text artifacts, layout, and
overflow extents. M9 remains authoritative for presentation-transform and final
paint/hit/focus/semantic correlation. This matrix adds only the editing, service,
scroll, controller, touch, and integrated observations required by M10.

```text

```

All rows are `Required`. Serial M10 delivery is M10B exact text mapping, M10C
transactional editing, M10D framework services, M10E interaction, then M10F
integrated closure. An application-independent editor document, second text
layout or shaping path, widget-private edit queue or scroll tree, framework
services smuggled through application `HostProtocol`, renderer/native semantic
authority, raw controller backend in runtime, or hidden control-specific path
cannot satisfy M10.

## Closure rule

M10 is conformance-complete only when all 28 rows are `owner-accepted` on the
accepted default branch. Each serial implementation slice must be separately
owner-accepted, squash-merged, accepted-main validated, and followed by bounded
current-truth/conformance reconciliation before its rows become
`owner-accepted`. M10 closes only after M10F integrated reconciliation and
accepted-main validation. Later M11–M13 work may consume these contracts but must
not move document, edit-chain, text-map, service, scroll, semantic, native-host,
or renderer authority elsewhere.
