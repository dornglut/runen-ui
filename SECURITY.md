# Security Policy

> **Category: Current contract**

## Supported versions

RunenUI has no production-supported release. The `0.x` workspace is experimental, package publication is disabled, and security fixes do not currently carry a guaranteed support window.

## Reporting a vulnerability

Do not post vulnerability details publicly. Use the repository's private **Security → Report a vulnerability** flow on GitHub. Include the affected revision or version, impact, reproduction, prerequisites, and any proposed mitigation.

If private vulnerability reporting is temporarily unavailable, open a public issue containing no vulnerability details and request restoration of a private reporting channel. Do not include exploit information, affected secrets, private data, or reproduction steps in that issue.

The project will assess usable reports, coordinate a fix and disclosure when appropriate, and credit reporters who request attribution. No response or remediation deadline is promised before a supported release policy exists.

Security reports do not replace ordinary correctness or API issues, which may use the public issue tracker when they contain no sensitive exploit information.
