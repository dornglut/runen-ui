# Code of Conduct

> **Category: Current contract**

RunenUI is owner-maintained, but its public project spaces must remain respectful, technically rigorous, and free from harassment.

Expected behavior includes constructive feedback, clear evidence, respect for differing experience and viewpoints, acceptance of correction, and focus on the project's users and technical contracts. Unacceptable behavior includes harassment, threats, discrimination, sexualized conduct, sustained disruption, personal attacks, deliberate exposure of private information, or retaliation against good-faith reports.

The repository owner may edit or remove content and restrict participation when behavior violates this policy. Enforcement decisions should consider context, impact, recurrence, and safety.

Use GitHub's private content-reporting or platform-abuse tools where available for conduct concerns. Do not include sensitive personal information in a public issue. A non-sensitive moderation issue may request private handling without describing private facts.

This policy applies to repository discussions, pull requests, issues, project communication, and public representation of the project.
